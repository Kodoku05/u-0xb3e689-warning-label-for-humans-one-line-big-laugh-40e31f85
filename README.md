A Python 3.13 standard-library program that writes one single-line safety warning label for every human being to `/output/entry.txt` — 139 characters, funny first and plausible second:

> WARNING: This human read the instructions exactly once, understood none of them, and will now improvise with total confidence. Stand clear.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output directory defaults to `/output`. The program creates it when needed.
